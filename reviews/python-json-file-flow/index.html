01새 폴더와 입력 준비하기

개인 Mac의 터미널·편집기와 기존 Python 3.11 이상을 사용합니다. 버전은 준비 기준이며 문법의 최소 버전은 아닙니다. 설치·로그인·외부 통신은 없습니다. 현재 위치·파일과 Python을 먼저 확인하세요.

pwd
ls
python3 --version
which python3

정상이라면 현재 경로·파일 목록, Python 버전·실행 경로가 나옵니다. Python이 없거나 준비 기준보다 낮으면 멈추고 환경 준비 도움을 받으세요. 기존 파일은 수정하지 않습니다.

이제 mktemp -d로 이름이 겹치지 않는 새 임시 폴더를 만들고 cd로 이동합니다. 이후에도 이 터미널을 사용하세요.

NBP_REVIEW_ROOT="$(mktemp -d /tmp/nbp-json-review.XXXXXX)"
cd "$NBP_REVIEW_ROOT"
pwd
ls -A

정상이라면 새 폴더 경로가 나오고 파일 목록은 비어 있습니다. 경로는 실행마다 다릅니다. 비어 있지 않으면 멈추고 새 폴더인지 확인하세요.

출력된 폴더를 편집기에서 열어 빈 review_json.py와 입력 파일 sale.json을 만듭니다. sale.json에는 아래 한 줄만 넣고 UTF-8로 저장하세요. Python 코드가 아니라 데이터 파일 내용입니다. 빈 Python 파일도 저장합니다.

{"region": "서울", "amount": 1200}

JSON은 데이터를 글자로 저장하는 형식입니다. 여기서는 {} 안에 항목 이름과 값을 :로 연결합니다. "region"·"amount"는 항목 이름이며 문자열에는 큰따옴표를 씁니다. 1200은 따옴표 없는 숫자입니다. 마지막 항목 뒤에는 쉼표를 붙이지 않습니다.

이름에 .txt가 자동으로 붙지 않았는지 확인합니다.

ls

정상 목록은 review_json.py와 sale.json입니다. 열 배치는 기기마다 다를 수 있습니다.

다음 명령으로 Python·새 폴더·두 파일을 확인했습니다. 경로의 마지막 부분은 실행마다 다릅니다.

python3 --version

저장한 입력은 아래 내용입니다.

{"region": "서울", "amount": 1200}

02파일 전체를 글자로 읽기

review_json.py 전체를 아래 코드로 바꾸고 저장하세요. open은 파일을 열며 "r"은 읽기 전용입니다. 파일명은 터미널의 현재 폴더에서 찾습니다. encoding="utf-8"은 저장된 글자를 UTF-8 방식으로 읽겠다는 뜻입니다.

with ... as file:은 열린 파일을 file이라는 이름으로 쓰고 들여쓴 작업이 끝나면 자동으로 닫습니다. read()는 파일 내용을 문자열로 읽습니다. text 변수에 결과를 담았으므로 파일을 닫은 뒤에도 읽어 둔 글자를 출력할 수 있습니다.

with open("sale.json", "r", encoding="utf-8") as file:
    text = file.read()

print(type(text))
print(text, end="")

type은 자료형, 즉 값의 종류를 알려줍니다. print는 화면에 표시합니다. end=""는 출력 끝에 줄바꿈을 추가하지 않는 설정입니다. 입력 파일의 줄바꿈이 있으면 그대로 나옵니다.

python3 review_json.py

정상 출력입니다. 두 번째 줄에 중괄호가 보여도 첫 줄은 문자열을 뜻하는 str입니다. 확장자가 .json이라고 read()가 항목을 자동으로 해석하지는 않습니다.

<class 'str'>
{"region": "서울", "amount": 1200}

FileNotFoundError이면 현재 위치·파일명·저장을 확인하고 멈추세요. 기존 다른 파일을 대신 읽지 않습니다. 한글이 깨지면 편집기의 UTF-8 저장을 확인합니다.

완료 예시

숫자 1200인 입력에서 다음 전체 코드를 실행했습니다.

with open("sale.json", "r", encoding="utf-8") as file:
    text = file.read()

print(type(text))
print(text, end="")
python3 review_json.py
<class 'str'>
{"region": "서울", "amount": 1200}

닫힌 파일과 읽어 둔 문자열을 구분했습니다. 아직 금액을 키로 찾은 상태는 아닙니다.

03다시 열어 Python 값으로 읽기

JSON의 항목을 해석해 값으로 바꾸는 일을 파싱이라고 합니다. import json은 Python에 기본으로 들어 있는 JSON 도구 모음을 가져옵니다. 별도 설치가 아닙니다. json.load(file)은 열린 파일에서 JSON을 읽어 Python 값으로 바꿉니다.

review_json.py 전체를 교체하세요. 앞의 read()를 남기지 않습니다. 끝까지 읽은 열린 파일은 읽는 위치도 끝에 있으므로 같은 파일 객체를 곧바로 json.load에 넘기지 않습니다. 아래에서는 새로 열어 처음부터 읽습니다.

import json

with open("sale.json", "r", encoding="utf-8") as file:
    sale = json.load(file)

print(type(sale))
print(sale["amount"])
print(type(sale["amount"]))
print(sale["amount"] + 100)

이번처럼 {}로 항목을 묶은 JSON 객체는 Python의 딕셔너리(dict)가 됩니다. 딕셔너리는 이름인 키와 값을 연결합니다. sale["amount"]는 키 "amount"의 값을 꺼냅니다. 따옴표 없는 정수 1200은 Python의 정수인 int가 되어 마지막 줄에서 100을 더할 수 있습니다.

python3 review_json.py

정상 출력입니다. 바깥 구조는 dict이고 그 안의 금액 하나는 int입니다.

<class 'dict'>
1200
<class 'int'>
1300

JSONDecodeError이면 입력의 큰따옴표·쉼표·중괄호와 전체 코드 교체를 확인하고 멈춥니다. KeyError이면 입력과 키의 철자를 대조하세요. 오류를 숨기는 코드는 추가하지 않습니다.

완료 예시

파일을 새로 열어 다음 전체 코드로 확인했습니다.

import json

with open("sale.json", "r", encoding="utf-8") as file:
    sale = json.load(file)

print(type(sale))
print(sale["amount"])
print(type(sale["amount"]))
print(sale["amount"] + 100)
python3 review_json.py
<class 'dict'>
1200
<class 'int'>
1300

이번에는 "amount" 키로 정수를 꺼내 계산했습니다.

04숫자에 따옴표를 붙이면 무엇이 달라질까?

작은 변형입니다. 편집기에서 sale.json 전체를 아래 한 줄로 교체하고 저장하세요. 금액의 숫자는 그대로이고 큰따옴표만 생겼습니다.

{"region": "서울", "amount": "1200"}

review_json.py 전체도 아래 코드로 바꿉니다. repr는 문자열의 따옴표처럼 값의 표현을 드러냅니다. print만으로는 숫자와 문자열이 비슷하게 보이므로 type과 함께 확인합니다.

import json

with open("sale.json", "r", encoding="utf-8") as file:
    sale = json.load(file)

print(type(sale))
print(repr(sale["amount"]))
print(type(sale["amount"]))
python3 review_json.py

정상 출력입니다. 바깥 구조는 여전히 딕셔너리이고 그 안의 금액만 문자열로 바뀌었습니다.

<class 'dict'>
'1200'
<class 'str'>

이 값에 숫자 100을 더하면 자동으로 숫자가 될까요? 아래 전체 코드로 교체해 확인합니다. 이 실행은 의도한 오류를 관찰하는 단계이며 성공 종료를 기대하지 않습니다.

import json

with open("sale.json", "r", encoding="utf-8") as file:
    sale = json.load(file)

print(sale["amount"] + 100)
python3 review_json.py

예상 결과는 계산값이 아닌 TypeError입니다. 마지막 줄은 다음과 같고 앞의 경로·줄 번호는 달라집니다. 다른 오류면 입력부터 확인하고 멈추세요.

TypeError: can only concatenate str (not "int") to str

파서는 큰따옴표로 감싼 값을 문자열로 읽습니다. 숫자처럼 보인다는 이유로 정수로 고쳐 주지는 않습니다. 여기서는 변환 코드를 추가하지 않고 입력을 복원합니다.

sale.json 전체를 다음 숫자 표기로 저장하세요. Python 코드는 방금 오류를 확인한 코드 그대로 둡니다.

{"region": "서울", "amount": 1200}
python3 review_json.py

정상 출력은 1300입니다. 파일을 고쳤다고 이미 읽은 변수의 값이 저절로 바뀌지는 않습니다. 프로그램을 다시 실행해 새로 읽었기 때문에 달라졌습니다.

완료 예시

문자열 입력에서 자료형 확인 코드는 dict, '1200', str을 출력했습니다. 다음 전체 코드는 같은 입력에서 TypeError로 종료됐습니다.

import json

with open("sale.json", "r", encoding="utf-8") as file:
    sale = json.load(file)

print(sale["amount"] + 100)
python3 review_json.py
TypeError: can only concatenate str (not "int") to str

입력을 아래 내용으로 복원하고 같은 코드를 다시 실행했습니다.

{"region": "서울", "amount": 1200}
python3 review_json.py
1300

의도한 오류 관찰과 정상 복구를 구분했습니다.

05입력 파일만 정리하기

with는 열린 파일을 닫는 것이지 디스크에서 삭제하는 기능이 아닙니다. 이제 이 글에서 만든 입력만 삭제합니다. review_json.py와 임시 폴더는 복습 기록으로 남깁니다.

정리 대상 종류: file

정리 대상 ID: sale.json

정확한 이름의 sale.json 입력 파일만 정리합니다. 다른 파일은 삭제하지 않습니다.

먼저 위치와 대상을 확인하세요. 준비 단계의 새 임시 폴더와 다르거나 직접 만든 입력인지 확신할 수 없으면 정리하지 않습니다.

pwd
ls

정상 목록은 review_json.py, sale.json입니다. 확인 후 정확히 아래 파일만 지웁니다. 삭제한 입력은 준비 단계의 한 줄로 다시 만들 수 있습니다.

rm ./sale.json

성공 시 출력은 없습니다. 빈 출력만으로 완료를 판단하지 말고 목록을 확인합니다.

ls

정상이라면 review_json.py만 남습니다. 이후 Python 코드를 재실행하면 입력이 없어서 FileNotFoundError가 나는 것이 맞습니다. 재실습하려면 숫자 JSON 파일부터 다시 만드세요.

완료 예시

새 임시 폴더임을 확인한 뒤 다음 명령을 실행했습니다.

rm ./sale.json
ls
review_json.py

삭제 명령의 출력은 없었고, 목록에서 입력만 사라진 것을 확인했습니다. 코드와 폴더는 보존했습니다.
