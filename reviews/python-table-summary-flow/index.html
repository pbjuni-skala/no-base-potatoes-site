01준비 상태 확인

macOS 터미널 또는 같은 명령을 쓰는 bash·zsh 환경에서 진행합니다. 수업에 사용하던 pandas가 설치된 Python을 먼저 선택하세요. 이 글의 python3는 그 Python입니다. 다른 명령 이름을 쓰는 환경이면 모든 실행 명령의 python3를 같은 이름으로 바꿉니다. 새 패키지는 설치하지 않습니다.

import pandas as pd는 표를 다루는 도구인 pandas를 불러와 pd라는 짧은 이름을 붙입니다. print()는 괄호 안의 값을 보여줍니다. 아래 -c 뒤 따옴표 안은 바로 실행할 Python 코드입니다. 버전과 불러오기 성공 여부를 확인합니다.

python3 -c 'import platform; import pandas as pd; print("Python", platform.python_version()); print("pandas", pd.__version__)'

정상 출력은 Python 버전과 pandas 버전 두 줄입니다. 제작 검증은 Python 3.12.14 / pandas 2.2.3에서 했습니다. command not found나 ModuleNotFoundError: No module named 'pandas'가 나오면 멈추고 수업용 Python 선택에 도움을 요청하세요. 임의로 시스템 전체에 설치하지 않습니다. 다른 버전에서 아래 결과와 다르면 버전과 오류를 함께 남깁니다.

기존 프로젝트를 건드리지 않을 새 임시 폴더를 만듭니다. mktemp -d는 겹치지 않는 빈 폴더를 만들고, NBP_REVIEW_ROOT는 그 경로를 기억합니다. cd는 폴더를 이동하고 pwd는 현재 위치를 보여줍니다.

NBP_REVIEW_ROOT="$(mktemp -d /tmp/nbp-table-review.XXXXXX)"
cd "$NBP_REVIEW_ROOT"
pwd
python3 -c 'from pathlib import Path; print("files:", list(Path(".").iterdir()))'

정상 출력은 새 임시 폴더의 절대 경로와 files: []입니다. 빈 목록은 기존 파일이 없다는 뜻입니다. 오류나 다른 파일이 보이면 다음 단계로 넘어가지 않습니다. 이 경로를 기록하고 같은 터미널을 사용하세요.

이후 편집기에서 이 임시 폴더의 review_table.py를 새로 만듭니다. 각 Python 코드 블록 전체로 이 파일 내용을 교체하고 저장한 뒤, 아래 실행 명령을 입력합니다. 코드를 이어 붙이지 않습니다. 새 임시 폴더가 아닌 기존 파일은 덮어쓰지 않습니다. 편집기에 파일을 저장하는 방법이 낯설면 여기서 도움을 받으세요. 원래 교안 저장소에는 파일을 만들지 않습니다.

완료 예시

준비를 다시 재현할 전체 명령입니다. 이미 준비했다면 읽고 비교만 합니다.

python3 -c 'import platform; import pandas as pd; print("Python", platform.python_version()); print("pandas", pd.__version__)'
NBP_REVIEW_ROOT="$(mktemp -d /tmp/nbp-table-review.XXXXXX)"
cd "$NBP_REVIEW_ROOT"
pwd
python3 -c 'from pathlib import Path; print("files:", list(Path(".").iterdir()))'

실제 실행에서 Python 3.12.14, pandas 2.2.3, 새 임시 경로, files: []가 순서대로 출력됐습니다. 임시 경로는 실행할 때마다 달라지며, 마지막 빈 목록은 파일을 덮어쓰지 않고 시작했다는 근거입니다.

02네 거래를 행과 열로 읽기

DataFrame은 행과 열에 이름을 붙여 다루는 표입니다. 가로 한 줄인 행은 여기서 거래 한 건, 세로 한 줄인 열은 지역·품목·금액 같은 항목입니다. region은 지역(East 동쪽, West 서쪽), item은 품목(soup 수프, rice 밥), amount는 그 거래의 금액입니다. 한 행이 지역 하나라는 뜻은 아닙니다.

입력의 {...}는 이름과 값을 짝짓는 딕셔너리이고, 각 이름 뒤 [...]는 그 열의 값을 순서대로 놓은 목록입니다. 같은 위치의 값끼리 한 거래를 이룹니다. 첫 거래는 East, soup, 1200입니다. df =는 만든 표를 df라는 이름으로 기억합니다.

실행 전에 행 수와 열 수를 예상하세요. shape는 (행 수, 열 수)를 알려줍니다. to_string(index=False)는 표를 문자열로 펼치되 왼쪽 행 번호를 숨겨 출력하는 표현입니다. 분석 결과를 바꾸지는 않습니다. 아래 전체 코드를 review_table.py에 저장합니다.

import pandas as pd
df = pd.DataFrame({
    "region": ["East", "East", "West", "West"],
    "item": ["soup", "rice", "soup", "rice"],
    "amount": [1200, 800, 1500, 500],
})
print(df.to_string(index=False))
print("shape:", df.shape)

저장한 파일을 실행합니다.

python3 review_table.py

정상 출력은 아래와 같습니다. (4, 3)은 거래 네 건과 항목 세 개이지 지역 네 개가 아닙니다. 줄맞춤 공백보다 열 이름·값·행 수를 비교하세요. 오류나 다른 값이 나오면 입력 네 건과 저장 여부를 먼저 확인합니다.

03조건을 고르는 자리와 열을 고르는 자리

“금액이 1000 이상인 거래의 지역과 금액만 보고 싶다”면 어떻게 할까요? df["amount"] >= 1000은 각 거래를 검사해 True(참) 또는 False(거짓)를 만듭니다. 이 참·거짓 목록을 불리언 조건이라고 합니다. 참인 행만 남기는 것이 조건 선택입니다.

.loc[행 조건, 출력할 열 목록]에서 쉼표 왼쪽은 어느 거래를 남길지, 오른쪽은 그 거래의 어떤 항목을 보여줄지 정합니다. 금액으로 검사한다고 금액 열을 반드시 출력해야 하는 것은 아닙니다. selected는 선택 결과의 새 이름입니다. 파일 내용을 아래 전체 코드로 교체하고 저장하세요.

import pandas as pd
df = pd.DataFrame({
    "region": ["East", "East", "West", "West"],
    "item": ["soup", "rice", "soup", "rice"],
    "amount": [1200, 800, 1500, 500],
})
selected = df.loc[df["amount"] >= 1000, ["region", "amount"]]
print(selected.to_string(index=False))
print("shape:", selected.shape)

선택 결과를 실행해서 확인합니다.

python3 review_table.py

정상 출력은 두 거래와 두 열입니다. 행을 묶어 합친 것이 아니라 입력에 있던 두 거래를 남겼습니다. 예상과 다르면 .loc의 쉼표 양쪽을 따로 확인하세요.

region  amount
  East    1200

shape: (2, 2)

04거래별 한 행을 그룹별 한 행으로 바꾸기

이번에는 선택한 두 건이 아니라 원본 네 건 전체에서 지역별 합계를 구합니다. “East 거래만 보여줘”와 “East 거래 금액을 모두 더해줘”는 다른 질문입니다.

groupby("region")은 같은 지역 값을 가진 거래끼리 묶을 기준을 정합니다. 이것만으로 합계가 나오지는 않습니다. 뒤의 ["amount"]는 더할 금액 열을 고르고, .sum()이 각 묶음 안의 값을 더합니다. 여러 행을 하나의 요약 값으로 만드는 것을 집계라고 합니다. as_index=False는 결과의 지역 이름을 보통 열로 남겨 읽기 쉽게 하는 설정입니다. pandas 2.2 그룹 기준과 결과 설정, 그룹 합계

전체 파일을 아래 코드로 교체해 저장합니다.

import pandas as pd
df = pd.DataFrame({
    "region": ["East", "East", "West", "West"],
    "item": ["soup", "rice", "soup", "rice"],
    "amount": [1200, 800, 1500, 500],
})
summary = df.groupby("region", as_index=False)["amount"].sum()
print(summary.to_string(index=False))
print("shape:", summary.shape)

지역별 요약을 실행합니다.

python3 review_table.py

정상 출력에서 East 한 행은 거래 한 건이 아니라 East의 두 거래를 합친 요약입니다. 숫자가 2000인 거래를 찾아낸 것이 아닙니다. 합계가 다르면 선택 결과가 아니라 원본 df로 묶었는지 확인하세요.

region  amount
  East    2000
  West    2000
shape: (2, 2)

작은 변형: 더할 금액은 그대로, 묶는 기준만 변경

지역 대신 품목으로 묶습니다. groupby의 기준만 "item"으로 바꾸고 나머지는 그대로 둡니다. 실행 전에 결과의 한 행이 무엇을 뜻할지 말해 보세요. 전체 파일을 아래 코드로 교체해 저장합니다.

import pandas as pd
df = pd.DataFrame({
    "region": ["East", "East", "West", "West"],
    "item": ["soup", "rice", "soup", "rice"],
    "amount": [1200, 800, 1500, 500],
})
summary = df.groupby("item", as_index=False)["amount"].sum()
print(summary.to_string(index=False))
print("shape:", summary.shape)

품목별 요약을 실행합니다.

python3 review_table.py

정상 출력은 품목별 두 행입니다. 기본 설정은 그룹 이름을 정렬하므로 rice가 먼저 나옵니다. 지역 합계와 행 수가 같아도 한 행의 의미는 다릅니다. 거래 금액은 바뀌지 않았지만 어떤 거래끼리 더했는지가 바뀌었습니다.

item  amount
rice    1300
soup    2700
shape: (2, 2)
완료 예시

아래는 저장할 전체 코드와 실제 실행 출력입니다. 같은 임시 폴더의 review_table.py를 이 코드로 저장합니다.

print(by_item.to_string(index=False))
print("original shape:", df.shape)

python3 -c 'from pathlib import Path; print("script exists:", Path("review_table.py").exists())'

정상 출력은 script exists: False입니다. rm -f 자체는 삭제 성공 또는 파일이 이미 없을 때 아무 글자도 출력하지 않습니다. 오류가 나거나 True라면 멈추고 위치를 확인하세요. 다른 파일 이름으로 바꿔 삭제하지 않습니다. 빈 임시 폴더는 남겨 두며 넓은 삭제 명령은 사용하지 않습니다.

import pandas as pd
df = pd.DataFrame({
    "region": ["East", "East", "West", "West"],
    "item": ["soup", "rice", "soup", "rice"],
    "amount": [1200, 800, 1500, 500],
})
selected = df.loc[df["region"] == "East", ["region", "amount"]]
summary = df.groupby("region", as_index=False)["amount"].sum()
print(selected.to_string(index=False))
print(summary.to_string(index=False))
